## 2. 关键设计决策与偏离

- **单一实现防漂移**：`compute_replay_times` 与 UI 实时用的 `Debouncer` 共用同一状态机；并**另设实时契约直测**（`on_event/due/fire`+封顶）。这条直测抓到了批式折叠看不见的 bug：`fire` 若不清 `pending`，只有直测红、批式仍绿——即"离线测一套、线上跑另一套"的老坑被这条守卫堵住。
- **复用同一条 apply 管线**：watcher 不另写生效逻辑，触发的是与手动「应用皮肤」**同一个** `do_apply` → 同样受"L1 不过不写注册表"、D11 原子替换、三态基线保护（§7 契约不因新入口而破）。
- **只认最终名**：worker 忽略 `*.tmp`（D11 的原子临时名），避免读到写一半的文件。
- **默认关闭 + 显式授权**：`watcher.enable` 默认 false；开启动作本身即用户授权"改图会自动换我指针"。§13 U23 与 §8 一致：这类改指针判据机器测不了，靠人眼 + 独立导出。
