## 3. 如实保留（未验，不影响 MVP 核心）

- **U17 `NWPen` 手写笔热点**：无手写笔设备无法实测。经用户同意，标注「未验」并收 V1.0。属手写/触控场景，不在 MVP 目标。
- **L3「逐槽」范围**：程序 L3 为被动采样，只能验采样时刻的活跃槽（探针点位置的 Arrow/文本光标等），无法主动逐一切到 15 槽分别采样。其余槽的生效由「统一生成管线 + 全 15 槽 L1/L2 + U8/U19 关键槽目测」间接保证。此为架构对「逐槽 L3」的真实边界，如实标注，不夸大为「每槽都做了 L3 像素比对」。
- **基线 ours 判定**：采用「规范化路径前缀 = applied_dir」，不误伤用户真实自定义光标（其路径不在我们 applied 目录下）；理论上用户把自定义光标恰好放进同名 `applied` 目录会误判，概率极低。

## 4. 结论

V1.0 = MVP 验收**通过**：三通道（.cur 透传 / PNG→cur / SVG→cur）端到端可应用、可 L3 生效、可干净还原；关键可见槽经真机目测校正。U17 与「逐槽 L3 全覆盖」如实标注为未验/边界，未打勾。
