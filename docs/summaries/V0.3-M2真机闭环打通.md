## 2. 关键设计决策

- **`do_spi` 必须显式**：`SPI_SETCURSORS` 是唯一当场改变用户指针的动作。沙箱测试一律 `false`；且 `SpiResult` 拆出 `performed`，「没执行」不再被记成「执行成功」。上一版 `restore`/`reset` 无条件调 SPI，等于测试也会重载真机方案 —— 已修。
- **基线是 apply 的前置条件而非附属品**：基线文件存在但读不出来 ⇒ **拒绝 apply**。原实现只看「在不在」，损坏时会照常写注册表，之后还原必然失败，用户只剩粗粒度 `--reset`。
- **三态不是两态**（实测背书）：`IBeam`、`Crosshair` 在本机是「值存在但空字符串」。把空串并入「不存在」，还原会把它们**删掉**而不是复原。
- **帧级 hotspot（U15）**：实测确认加载器不在帧之间换算热点，故 `CursorSpec` 的热点下沉到 `Frame`，新增 `scale_hotspot()` 按 `round(v*to/from)` 换算。顺带修掉一条**原本会假绿**的断言（旧写法 `m48.hotspot == 1` 只在「各帧热点相同」这个错误行为下成立）。
- **还原不依赖记忆**：`--live-check` 用 RAII guard 还原，任何中途 return 都还原；另外在程序之外留了一份人工现场备份（`state/manual-export-before-live.json`），万一 guard 与快照同时失效仍有人工复原路径。
- **动词表加 `Arity` 列**：需要目录参数的动词由表声明，`MissingOperand` 与 `Unknown` 是可区分的两种错误。

## 6. 遗留问题与下一步

**遗留**

- U4（设置项抢占）、U18（`CursorBaseSize` 语义）、U19（对角镜像）三项开放；U19 需要**换夹具**才能验。
- `--reset` 与 `--restore` 的真机路径尚未在真机上跑过（沙箱已验；真机只跑过 `--live-check`，其内部走的是同一段还原代码 + guard）。
- 非 ASCII 路径的命令行参数不可靠（`main` 用的是 ANSI argv）。GUI 阶段一并解决，已在 `verbs.cpp` 注释里标明是已知限制而非已解决。
- 真机 `applied\` 下 15 个 .cur 在还原后仍在（还原只回滚注册表，不删文件）。是否该删属产品设计，进 BACKLOG。

**下一步（M3 / V0.4）：PNG 通道**

前置已清（U15 帧级热点已落地，`stb_image` 已在仓库，不依赖网络）。要点：
1. `png_source`：stb 解码 → straight→premultiplied → 按 16/32/48 缩放 → 每帧热点用 `scale_hotspot` 换算；无 alpha 输入按 §4.2 走「AND 全 0 + alpha 255」，不做亮度抠图。
2. 预乘必须在这里做对 —— U13 已证明「每通道 ≤ alpha」对全不透明输入**完全测不出来**，所以 golden 夹具必须含半透明像素。
3. 新负对照：全不透明但故意不预乘的图（该漏检的形态）、`alpha=0` 且带颜色的图、尺寸小于最小档不放大。
4. M3 开工前需要一次 `Q:` 讨论：D8 的档位是否含 24（XCursor 常见）与 64/96（高 DPI）。
